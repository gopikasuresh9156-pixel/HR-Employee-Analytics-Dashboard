# HR Employee Analytics Dashboard

An interactive Power BI dashboard designed to analyze **employee and HR information**. The dashboard provides insights into employees, departments, job roles, experience, salary, and employment status.

### Employee Analysis

This page provides insights into total employees, departments, designations, job roles, experience, and employment status. It helps understand employee distribution and workforce information.

### HR Analysis

This page provides insights into salary, employee experience, department performance, and workforce trends. It helps HR teams understand employee data and make better decisions.

### Tools Used

- Power BI
- Excel
- Data Visualization
- Data Analysis

### Key Features

- Total employee analysis
- Department-wise employee analysis
- Designation and job role analysis
- Experience analysis
- Salary analysis
- Employment status tracking
- Interactive slicers and filters
- KPI cards
- Interactive charts and tables
